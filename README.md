# 文明之路

一款借鉴《文明6》玩法的网页回合制策略游戏，规则做了简化，上手更轻松。纯 HTML + JavaScript + Canvas，无需安装任何依赖。

当前版本：1.0

## 运行

- 直接双击 `index.html` 用浏览器打开即可游玩（推荐 Chrome / Edge）。
- 或者在项目目录启动一个本地服务器：

  ```bash
  python -m http.server 8380
  ```

  然后访问 <http://localhost:8380>。

存档保存在浏览器的 localStorage 中：每回合自动存档，菜单里还可以手动存档 / 读档。

## 玩法

开局选择文明（8 个，各有特色加成）、地图大小、对手数量、难度和游戏速度（快速 160 回合 / 标准 250 回合）。

- **城市**：开拓者建城，人口自动在最好的地块上工作；食物让人口增长，生产力用来造单位、建筑和奇观，金币可以直接购买；文化让边界扩张。
- **科技树（30 项）与市政树（19 项）**：科技解锁单位、建筑、奇观；每项市政直接提供永久加成。满足“尤里卡 / 鼓舞”条件时进度 +50%。
- **单位**：19 种陆地单位，从勇士到坦克；可升级、可积累经验晋升；可登船渡海。
- **战斗**：《文明6》式伤害公式，地形防御、驻扎加成；远程攻击无反击；城市有城防和远程攻击，生命归零后近战单位可以占领。悬停在目标上可以看到伤害预测。
- **外交**：与相遇的文明宣战或求和，电脑也会主动宣战 / 求和。
- **其他**：部落村庄奖励、蛮族营地、11 座奇观、迷雾探索。
- **胜利方式**：科技胜利（完成 3 项太空计划）、文化胜利（完成“全球化”并拥有 3 座奇观）、征服胜利（占领所有对手的原首都）、分数胜利（回合上限时分数最高）。

### 相比《文明6》的简化

没有区域、宗教、宜居度、住房、伟人、贸易路线、政策卡和海军单位；市民自动分配；城市生产列表有“推荐”标记，也可以勾选“自动生产”；建造者和侦察兵可以自动工作 / 探索。

### 操作

| 操作 | 方式 |
| --- | --- |
| 选择单位 / 城市 | 左键 |
| 移动 / 攻击 | 右键；或选中单位后左键点击蓝色可达地块、远处地块、红框目标 |
| 平移 / 缩放 | 拖动地图、`WASD` / 方向键；滚轮、`+` `-` |
| 结束回合 | `Enter` |
| 下一个待命单位 | `Tab` |
| 科技树 / 市政树 | `T` / `C` |
| 显示产出 / 网格 / 回到首都 | `Y` / `G` / `H` |
| 单位命令 | `B` 建城、`I` 建造改良、`F` 驻扎/睡眠、`E` 自动探索、`U` 升级、`M` 移动、空格 跳过、`Del` 解散 |

## 项目结构

```
index.html        页面骨架
css/tokens.css    设计变量与基础组件
css/game.css      游戏界面样式
js/data.js        数据：地形、资源、单位、建筑、奇观、科技、市政、文明
js/util.js        随机数、噪声、六边形坐标
js/mapgen.js      地图生成
js/game.js        规则核心：城市、单位、战斗、研究、回合、胜利、存档
js/path.js        寻路
js/ai.js          电脑对手与蛮族
js/render.js      Canvas 地图渲染
js/ui.js          界面与交互
tools/simulate.js 无界面对局模拟（平衡测试）
```

游戏规则（`data.js`～`ai.js`）不依赖浏览器，可以用 Node 跑电脑对电脑的完整对局来测试平衡和稳定性：

```bash
node tools/simulate.js 12345 standard normal
```

参数依次为：种子、地图大小（small / standard / large）、难度（easy / normal / hard）、回合数、速度（quick / standard）。
